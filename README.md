## What is this?

[EZOBLOCKER](https://ezoblocker.app) is a DNS based blocker for phones: ads, trackers, scams and the categories a family chooses.
Most of what it blocks comes from great community lists (HaGeZi, OISD, Block List Project, AdGuard and others).
**This repository holds only what those lists did not have yet**, the names our own research found:

- 🔎 **Search discovery:** daily web searches per country and category, every candidate checked on its own homepage and reviewed by a language model before it gets in.
- 📱 **App lab:** popular and brand new Android games and apps run on our own test phones; we record which ad and tracking endpoints they call and read their packages for SDK hosts. Our own test devices only, never anyone's real traffic.
- 🎰 **Bookmaker directories and mirror hunting:** official domains of betting sites, Telegram "new address" posts, redirect chains.
- 🧩 **Ad tech sources:** bidder endpoints from Prebid.js and Prebid Server (Apache-2.0) that no list covered.

We pay for the search and model APIs ourselves and give the result away. 💚

## Formats

| Folder | Looks like | For |
|---|---|---|
| `lists/` | `*.example.com` / `example.com` | Blocky, dnsmasq style tools; `*.` means the domain and every subdomain |
| `adblock/` | `\|\|example.com^` | AdGuard Home, AdGuard, uBlock Origin, NextDNS, Pi-hole (v6 ABP syntax) |
| `hosts/` | `0.0.0.0 example.com` | hosts files, Pi-hole, routers |
| `domains/` | `example.com` | anything that takes one domain per line |

Use the raw links above; they always point at the newest version.
